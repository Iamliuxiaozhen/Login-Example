# Login Example 隐私政策

**最后更新日期：2026年9月4日**

本政策说明 **Login Example**（以下简称“本项目”）如何处理信息。本项目是开源 OAuth 登录演示，不作为生产级个人信息收集或保存服务使用。

## 一、信息处理

默认实现只使用第三方授权码和访问令牌完成演示流程，不主动保存、出售、共享或分析用户资料。自行部署或修改本项目的个人或组织可能采用不同的数据处理方式，并应自行负责隐私政策。

## 二、第三方服务

GitHub、Microsoft、Google 和 Cloudflare 按其自身政策处理信息。授权前请阅读相关平台的政策。本项目与上述平台不存在官方关联。

## 三、Cookie 与安全

功能性 Cookie 可能用于维持演示会话以及保存短期 OAuth 或 Turnstile 状态。部署时应使用 HTTPS 并妥善管理密钥。删除或阻止 Cookie 可能导致登录无法使用。

## 四、未成年人、更新与联系

本项目面向开发者和学习者。未成年人应在监护人同意下使用。政策变更会以新的日期发布。问题可通过项目 GitHub 的 Issues 或 Pull Requests 提交。
