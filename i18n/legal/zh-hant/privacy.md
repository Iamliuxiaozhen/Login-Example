# Login Example 隱私政策

**最後更新日期：2026年9月4日**

本政策說明 **Login Example**（以下稱「本專案」）如何處理資訊。本專案是開源 OAuth 登入示範，不作為生產級個人資訊收集或保存服務使用。

## 一、資訊處理

預設實作只使用第三方授權碼與存取令牌完成示範流程，不主動保存、出售、分享或分析使用者資料。自行部署或修改本專案的個人或組織可能採用不同的資料處理方式，並應自行負責隱私政策。

## 二、第三方服務

GitHub、Microsoft、Google 與 Cloudflare 依其自身政策處理資訊。授權前請閱讀相關平台政策。本專案與上述平台不存在官方關聯。

## 三、Cookie 與安全

功能性 Cookie 可能用於維持示範工作階段，以及保存短期 OAuth 或 Turnstile 狀態。部署時應使用 HTTPS 並妥善管理密鑰。刪除或封鎖 Cookie 可能導致登入無法使用。

## 四、未成年人、更新與聯絡

本專案面向開發者與學習者。未成年人應在監護人同意下使用。政策變更會以新的日期發布。問題可透過專案 GitHub 的 Issues 或 Pull Requests 提交。
